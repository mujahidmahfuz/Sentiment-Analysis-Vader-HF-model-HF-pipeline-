A clean and production-ready **sentiment analysis project** built using **Hugging Face pre-trained transformer models**.  
This repository includes a complete Jupyter Notebook demonstrating:

- Dataset loading  
- Text preprocessing  
- Sentiment inference  
- Batch sentiment prediction  
- Visualizations  
- Clean and modular code  

---

## 📘 Project Overview

This project performs **sentiment classification** using state-of-the-art transformer models.  
It is ideal for:

- NLP beginners  
- Students/researchers building ML baselines  
- Developers adding sentiment features to apps  
- Anyone learning Hugging Face Transformers  

---

## 🧠 Model Used

The notebook uses Hugging Face’s simple and powerful **`pipeline()`** API.

Supported models (plug & play):

- `distilbert-base-uncased-finetuned-sst-2-english`  
- `bert-base-uncased`  
- `cardiffnlp/twitter-roberta-base-sentiment`
